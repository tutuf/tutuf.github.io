*Client story · [laptop.bg](https://laptop.bg)*

# Built for the business it became

laptop.bg started as an online store. Over seventeen years, it grew into the production system behind daily commercial operations - catalogue, suppliers, payments and sales channels. We changed it repeatedly without discarding the business knowledge already built into it.

The recurring question was rarely, “How do we add this feature?” It was:

- **What should be configurable?**
- **What should be connected to something that already exists?**
- **What was specific enough to deserve custom software?**
{: .lenses role="list"}

---

## A product model the business could reshape

From early on, the laptop.bg team could define product categories and their technical characteristics themselves, then choose which characteristics customers saw as filters. When smartphones became an important category, the business introduced it without new category-specific development from us.

The same foundation later supported the catalogue for laptop.bg’s own G:RIGS brand.

## Many supplier formats. One stable model

Suppliers provided data in their own XML and JSON formats. We created the original concept and architecture for a mediation layer, then built its first version. It translated those different feeds into one shared format.

We also built and maintained the integration that allowed the core system to depend on that format alone.

We implemented laptop.bg’s commercial rules for choosing the best offer when the same product was available from more than one supplier.

## New channels without a second commerce system

The same catalogue and order flow came to serve demand that did not arrive through laptop.bg’s own storefront.

We built a dropshipping API that let partner stores and B2B customers place orders against the existing system. Once the API was in place, a new partner could be added without writing new code in the core system.

When international sales became relevant, we made the necessary changes in the core application and connected it to easySales rather than building a second storefront. The first integration was designed so that adding another supported market would require only a small, bounded code change and a few configuration updates.

Both allowed laptop.bg to reach new customers through the system it already had, without building a separate commerce system for every new channel.

## The business kept the freedom to decide

Over seventeen years, the system grew with a real business. Some parts were built by us, some connected the system to software made by others, and some were later developed further by other teams. Throughout, the business kept the system, the knowledge and the freedom to decide what came next.
